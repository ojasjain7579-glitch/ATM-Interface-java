📌 Project Overview
This project is a Java-based ATM Interface System developed as part of the Oasis Infobyte Internship Program. The system simulates basic ATM functionalities commonly found in real-world banking applications.

It is a console-based application that allows users to perform banking operations in a secure and structured manner using Java programming concepts.

🎯 Objectives of the Project
To understand and implement real-world banking operations in Java
To apply Object-Oriented Programming (OOP) concepts
To develop a user-friendly console-based application
To improve logical thinking and problem-solving skills
⚙️ Features
🔐 PIN Authentication System to secure user access
💰 Deposit Functionality to add money to account
💸 Withdraw Functionality with balance validation
📊 Balance Inquiry to check current account balance
🚪 Exit Option to safely terminate the session
🛠️ Technologies Used
Java (Core Java)
Object-Oriented Programming (OOP)
Scanner Class for user input handling
Conditional statements and loops
🧠 Concepts Used
Classes and Objects
Methods and Functions
Encapsulation
Control Statements (if-else, switch-case, loops)
Input/Output Handling
🎓 Learning Outcomes
Through this project, I gained practical knowledge of:

Designing console-based applications in Java
Implementing real-life banking logic
Handling user input securely and efficiently
Strengthening core Java programming fundamentals
📌 Conclusion
The ATM Interface project successfully demonstrates how basic banking operations can be simulated using Java. It helped in improving programming skills and understanding real-world application development during the internship period.
